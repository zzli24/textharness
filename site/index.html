Capabilities

功能按大类看

点开任意一类，看它具体能做什么。

01 编辑与文本 编码、换行、大文件、列编辑、查找替换、结构辅助
  • 编码不糊：自动识别 UTF-8 / BOM / GBK / UTF-16，保存前做往返检测，宁可报错也不静默丢字
  • 换行可控：CRLF / LF 识别、切换、原样还原
  • 大文件不炸：超过 8MB 先问，可只读打开前 3MB，保存强制另存，绝不截断原文件
  • 外部改动不丢：每 4 秒检测，被别的程序改了会问是否重载；崩溃后重启能还原未保存内容
  • 编辑手感：多标签、列选择列粘贴、正则查找替换、语法高亮、折叠、缩进参考线、彩虹括号、Ctrl + 滚轮缩放
  • 结构看得清：光标停在括号上会高亮配对并画出参考线；JSON 写错当场标红，Ctrl+Shift+M 看问题列表
02 表格与对比 CSV 表格视图、行级 diff、JSON 格式化
  • .csv 双击就是表格：Tab 走格、右键增删行列、改完存回去还是 CSV，Excel 和脚本都能直接读
  • 并排 diff：行级对比，红绿高亮，顶部给「相同 / 新增 / 删除」统计
  • JSON 一键格式化：缩进成两空格或压成一行，报错精确到行列
03 agent 与工作区 直接读写文件、22 个工具、随时可停
  • 不是贴代码：列目录、读文件、正则搜索、改内容、新建文件，直接在工作区里动手；写完自动在编辑器打开
  • 改动可回退：写文件前有确认与 diff，改错了能撤销
  • 多步自主：最多 16 步连续调用工具，大文件会分段读并自己接着读
  • 随时叫停：停止按钮即时中断，重试退避中也能立刻停
  • 花钱看得见：每轮显示 token 用量（输入 / 输出 / 缓存命中）；限流与网络错误自动重试，鉴权错误直接报错
04 记忆与归档 跨会话记住偏好，知识沉淀成草稿再入库
  • 三档记忆：长期事实每轮注入、会话结论只带最近几条、长模板单独存放不占上下文
  • 归档草稿：选中内容 → 草稿队列 → 整篇 diff → 确认写入知识库，随时撤销
  • 追加与插入：可以追加到已有文档，也可以指定插到某个小节之后
05 外部工具（MCP） 把别的服务接进来，逐台设策略
  • 三种接入：本地进程（stdio）、HTTP、SSE 都支持；配置格式与 Claude Desktop 的 mcpServers 一致
  • 逐台策略：写操作需确认 / 全部需确认 / 全部允许
  • 也能让 agent 配：把 JSON 贴给它，它解析后弹出确认框，你点确认才写配置
06 安全边界 哪些事它做不了，写清楚
  • 往 知识库 / 记忆 写东西，必须先确认，默认不写
  • 执行脚本、调用外部工具、访问工作区外的文件，都要你点头
  • agent 只能「提议」修改配置，不能自己动配置文件
  • 配置、会话、记忆全在你本机；除了模型请求本身，不上传任何内容
Fit

适合谁

说清楚不做什么，比堆功能更有用。

适合

  • 每天开一堆 .md / .sql / .json，想让 AI 直接改文件
  • 想要「记事本 + 会动手的助手」，而不是 IDE + 一堆插件
  • 在意编码、换行、大文件这些底层细节

不适合

  • 需要调试器、Git 图形化、重构的完整 IDE
  • 需要团队协作、云端同步
  • 想完全离线跑本地大模型（目前走 OpenAI 兼容接口）
