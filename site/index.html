Capabilities

不是又一个记事本

编辑器该有的它都有；不一样的是它自己会动手，还替你把表格和对比一起做了。

🤖

能读写工作区的 agent

列目录、读文件、正则搜索、写文件，最多 16 步自主完成。读大文件会分段返回并自己接着读，不会停在半截。

📊

CSV 表格视图

.csv / .tsv 双击就是表格：Tab 走格子、右键增删行列、Ctrl+S 原样存回 CSV。

🔀

文本对比窗口

行级 diff，左右自动对齐，增删改红绿高亮，顶部直接给「相同 / 新增 / 删除」统计。

🧾

JSON 一键格式化

状态栏点一下缩进成两空格，也能压成一行；格式有错时精确提示到第几行第几列。

🧮

列选择 / 列粘贴

点右下角「列」或按住 Alt 拖拽框选矩形区域，整列复制、按行分发粘贴。

🖼

截图直接入库

Ctrl+V 粘贴截图，自动落到 .assets/img/日期/，光标处插入链接，悬停出缩略图。

🔤

编码不乱码

自动识别 UTF-8 / BOM / GBK / UTF-16，保存前做编码往返检测，宁可报警也不静默丢字。

📂

按日期归档

新建文档 Ctrl+S 直接落进当天日期目录，同名自动加序号，不打断思路。

Tables

表格能直接改，不用绕去 Excel

表格不是"插进 Markdown 的图片"，而是真实的 CSV 文件。改完存回去还是 CSV， Excel、数据库、脚本都能直接读。

➕

建表

状态栏「建表」问你要几行几列，直接开一个 未命名-N.csv 标签，行号列标都固定。

⌨️

像 Excel 一样编辑

Tab 下一格、Enter 下一行、方向键上下走；从 Excel 复制一块区域，Ctrl+V 直接铺开。

🔄

和 Markdown 互转

笔记里选中表格 → 一键变 CSV 标签；表格右键「复制整表为 Markdown」→ 贴回文档。

👀

源码随时看

表格上方一键切「源码」，看原始 CSV、改分隔符、确认转义，都不会破坏文件。

两种主题之外，还能给整窗铺一张底图。面板会自动变半透明，正文压一层薄雾， 背景再花文字也看得清。

🌌

5 套内置预设

深夜蓝、暮色紫、晨曦橙、森林青、石墨灰——点一下就能换，缩略图直接看效果，不需要找图。

✂️

自定义图片可裁范围

选一张自己的图，会弹出 16:9 取景框：拖动平移、滚轮缩放， 框里看到什么，铺上去就是什么。确认后输出 1600×900 存进工作区 .assets/bg/，原图不动。

🎚️

三个滑杆调手感

不透明度 5–90%、模糊 0–24px、暗化 0–85%。暗化会跟着主题走（深色压黑、浅色压白），用来保住文字对比度。

🧩

图片跟着工作区走

背景图不是"记在本机路径"里，而是复制进工作区，换电脑、备份、同步都不会丢图。

不占菜单位置，需要的时候就在鼠标底下。

大小写转换、首字母大写、升序 / 降序 / 按长度排序、删除重复行——整理 IN (...) 列表和日志时很省事。

本文查找 / 文件夹搜索

深浅主题

Under the hood

基于 Chromium 内核

界面跑在 Electron 33（Chromium + Node）里，编辑器内核是 CodeMirror 6。 这决定了它的能力边界，也解释了安装包为什么是 77 MB 而不是 5 MB。

🌐

Chromium 渲染

界面由 Chromium 绘制，排版、字体、高分屏缩放、深浅主题和浏览器一致。 代价是安装包里约 180 MB 是 Chromium 运行时（未压缩），编辑器自身代码只有 2 MB。

⌨️

CodeMirror 6

编辑器内核用 CodeMirror 6，列选择、查找替换、括号闭合、语法高亮 都来自它的官方扩展——这也是它能对齐 Notepad++ 关键操作的原因。

🔒

本地优先

文件只在你本机读写，不上传任何服务器。AI 面板只在你主动提问时把对话和它读到的文件内容发给模型， API Key 存在本机配置文件里。

安装包尚未做代码签名，Windows 首次运行可能提示 SmartScreen：点「更多信息 → 仍要运行」即可。
安装包为什么有 77 MB？
体积几乎全部来自 Electron 运行时（Chromium + Node，未压缩约 180 MB）， 编辑器自身的代码只有 2 MB。换来的是稳定的编辑器内核与渲染能力； 已裁掉多余语言包并开启极限压缩。
表格是 CSV 还是编辑器里的"表格对象"？
是真实的 .csv / .tsv 文件。表格只是它的可视化视图， 改动会写回文本、保存时仍是标准 CSV，Excel 和脚本都能直接读。 这样它不会破坏纯文本编辑器的能力（行号、列选择、逐行 diff、百万行文件）。
必须联网才能用吗？
编辑、表格、对比、格式化全部离线可用。只有右侧 AI 面板需要你配置模型接口 （OpenAI 兼容的 Base URL + 模型名 + API Key），不配置也不影响其它功能。
提示「Windows 已保护你的电脑」怎么办？

这是 SmartScreen 对没有代码签名、也没有下载声誉的新程序的默认拦截， 不代表文件有问题。三种绕过方式：

  1. 点弹窗里的「更多信息」，再点右下角出现的「仍要运行」
  2. 右键 exe → 属性 → 勾选底部的「解除锁定」→ 确定，再双击
  3. PowerShell 执行 Unblock-File .\TextHarness-{{VERSION}}-setup.exe

该下 arm64 还是 x64？
左上角苹果菜单 →「关于本机」：写着 Apple M1/M2/M3/M4 的选 arm64； 写着 Intel Core i5/i7/i9 的选 x64。选错也能跑（Rosetta），只是慢一些。

三步开始用

  1. 双击 TextHarness-{{VERSION}}-setup.exe，选安装目录，下一步到底。
  2. 首次启动在「设置」里确认工作区目录（草稿、知识库、图库都放它下面）。
  3. 右侧 AI 面板首次打开会提示配置：填 Base URL、模型名、API Key（只有 Key 必填），存本机不外传。
卸载：设置 →「应用」→ TextHarness → 卸载，或安装目录里的 Uninstall TextHarness.exe。卸载会保留你的配置和工作区文件。
